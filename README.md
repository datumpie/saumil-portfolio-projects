# Portfolio Projects

Four data-analytics portfolio projects, each following the same 5-section
build standard: Business Problem & Research (10 Core Questions),
Architecture & Design (Decision Log), Implementation, Testing &
Validation, and Deployment/Maintenance/Future Enhancements.

| # | Project | Stack | Status |
|---|---|---|---|
| 1 | [Diamond Road Trip Optimizer](./project-1-diamond-road-trip-optimizer) | Python, live MLB Stats API, SQLite, Power BI | Complete |
| 2 | [The True Breakfast Commodity Index](./project-2-breakfast-commodity-index) | Python, live FRED API, pandas, SQLite, Power BI | Complete |
| 3 | [Bark in the Park Concession Optimizer](./project-3-bark-in-the-park-optimizer) | Python, NumPy, SQLite, SQL, Power BI | Complete |
| 4 | *(next up)* | -- | Not started |

Each project folder is self-contained: a `README.md` with the full
write-up, the working script(s), a `requirements.txt`, a `tests/` folder
with an automated pytest suite, and a `docs/` folder with Power BI setup
instructions and a Verification & Reproducibility checklist.
